History debug

Everything the pen sends, hover included. Move events arrive once per screen frame; raw updates arrive as fast as the pen reports; coalesced points are the in-between samples a move event carries. The interval chart plots the finest of those this browser gives. The charts show the last 6 seconds; the buffer holds much longer — set how long with Hold, watch the count below, then Download capture for the whole thing. Download a file rather than pasting: a paste gets reflowed and truncated on the way, and the file says for itself which browser and pen made it. Copy CSV is for a quick look, not for handing over.
