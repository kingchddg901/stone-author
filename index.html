Stone Author

a marble studio in one HTML file

You draw where the lines go. The stone happens.

It runs entirely in your browser — no install, no account, no upload. The slab is the document: a .json file that renders to the same picture every time, at any size from a thumbnail to 65,535 pixels wide.

Open the studio Gallery Source
  • Veins, branches, webs, stylolites, breccia, drusy, granite speck fields — each one a mark you place, not a preset you pick.
  • A coat tier over the top: subsurface glow, specular, one movable light, and a lens that refracts.
  • Black light and any other spectrum, with per-layer emission — the same slab under a different lamp.
  • Exports the picture, the coverage masks, vein id and t maps, an .ora with a layer per authoring layer, the vectors as SVG, and the slab itself.

Past 16,384 pixels the export streams the picture in bands straight into a PNG, so the whole image never exists at once. The largest measured: 65,535 × 40,959 — 2.68 gigapixels — written in a browser tab in eleven minutes, and rendered twice to identical bytes.
